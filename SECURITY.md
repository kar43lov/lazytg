# Security Policy

Please report security vulnerabilities **privately** via GitHub Security Advisories on this repository:

<https://github.com/kar43lov/lazytg/security/advisories/new>

Do not open public issues for security bugs.

The full threat model, ban-risk policy for unofficial Telegram clients, and disclosure timeline live in [`docs/SECURITY.md`](docs/SECURITY.md). Please read that page before filing.

## Supported versions

lazytg is in alpha. Only the latest released minor version receives security fixes.

| Version  | Supported |
|----------|-----------|
| latest   | yes       |
| older    | no        |
